# Appendix A: Suggested Naming Conventions

[Back to Docs Index](../README.md)

### Rust Crates

- use kebab-case folder names
- use snake_case module names
- prefer explicit crate naming by responsibility

### TypeScript Packages

- use scoped package names such as `@ai-traffic-os/ui-kit`
- keep runtime packages separate from config packages

### API Resources

- plural nouns for collections
- stable resource IDs with typed prefixes when useful

Examples:
- `ten_...`
- `prj_...`
- `key_...`
- `rtp_...`
- `req_...`
