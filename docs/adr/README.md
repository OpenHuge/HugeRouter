# ADR Index and Suggested Topics

[Back to Docs Index](../README.md)

This directory is reserved for architecture decision records (ADRs). Each ADR should capture the context, decision, alternatives considered, consequences, and follow-up actions for a major technical choice.

Suggested file naming convention:

```text
0001-why-rust-and-axum.md
0002-why-tanstack-start.md
0003-why-turborepo-for-workspace-orchestration.md
0004-why-mantine-for-console-ui.md
```
